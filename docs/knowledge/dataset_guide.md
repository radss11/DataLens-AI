# Dataset guide

The bundled demonstration dataset is the Gapminder country-year dataset exposed by Plotly Express. Each row represents one country in one year. The fields are country, continent, year, lifeExp, pop, gdpPercap, iso_alpha, and iso_num.

Interpretation notes:
- `lifeExp` is life expectancy.
- `pop` is population.
- `gdpPercap` is GDP per capita.
- `year` is the observation year.
- Country and continent are categorical dimensions.

The dataset is useful for demonstrating trend analysis, segmentation, geographic comparison, and conversational analytics. It should not be treated as a current real-time business dataset.
